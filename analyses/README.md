# Re-analyses of public ME/CFS data

Each folder holds the scripts, small results and a README with inputs and findings. Large inputs are hosted at data.solvingmecfs.org and listed in the [data catalogue](https://solvingmecfs.org/data). The atlas cites these as "Solving ME/CFS re-analysis".

- [`aromatic-lactates`](aromatic-lactates/): Metabolome-wide meta-analysis across 10 blood cohorts (aromatic lactates)
- [`biomapai-reanalysis`](biomapai-reanalysis/): Re-analysis of the BioMapAI (JAX) multi-omics cohort
- [`decodeme-genetics`](decodeme-genetics/): DecodeME summary statistics re-analysed (loci, MAGMA, colocalisation, genetic correlation)
- [`epi-literature`](epi-literature/): Finnish registry enrichments, ClinicalTrials.gov results and literature map
- [`microbiome-ipa`](microbiome-ipa/): Gut microbiome function behind low IPA and indolelactate
- [`mr-proteome`](mr-proteome/): Mendelian randomisation, MVP/FinnGen replication and cis-pQTL protein screen
- [`pem-germain2022`](pem-germain2022/): Post-exertional response re-analysis of the Cornell 2-day CPET metabolomics
- [`proteome`](proteome/): Blood and CSF proteomics, extracellular vesicles and cross-omics convergence
- [`round1-replication`](round1-replication/): Round 1: public ME/CFS cohorts re-analysed (metabolomics, NIH Walitt, transcriptomics)
- [`singlecell-methylation`](singlecell-methylation/): Single-cell PBMC, DNA methylation and B/T-cell repertoire re-analysis
